# AI 新手入门学习体验设计

## 目标

把现有“AI 新手入门”从百科与外部资源合集，调整为一套轻量、可操作、可返回的入门学习体验。用户不需要技术背景，也不需要注册账号；每章通过短内容、工作案例和小练习，逐步建立会分工、会表达、会判断三项核心工作能力。

“会负责”不在本期单独成章，只保留一条基本原则：AI 可以辅助分析，最终判断与交付仍由人负责。待公司正式安全与合规内容完备后，再增补独立章节。

## 1. 内容依据

本期内容以现有知识库与 Rita 的 Obsidian 沉淀为基础，重点复用：

- 《大模型工作原理》：Token 续写、预训练与推理、上下文不是长期学习；
- 《AI Fluency 4D 框架》：Delegation、Description、Discernment 的协作主线；
- 《Prompting 101 — Anthropic 官方工作坊》：目标、背景、任务、规则与迭代；
- 《Prompt Engineering 与学习方法》：上下文、结果校准、评估与多轮协作；
- 《大模型幻觉与四种缓解方案》：幻觉根源与证据核验；
- 《人的三种不可替代能力》与《道德责任不可外包》：人的判断与最终责任。

页面不照搬原笔记的技术深度，只提炼适合非技术职场用户的稳定概念和方法。

## 2. 信息架构

采用“学习目录页 + 6 个章节详情”的结构，延续“轻门户 + 强阅读”的视觉骨架。

### 2.1 学习目录页

`learn.html` 只承担学习导航：

- 首屏保留现有小A学习形象；
- 展示本次浏览的章节进度，例如 `已看 2 / 6`；
- 提供“继续学习”快捷入口；
- 展示 6 张章节卡，状态为 `未看 / 正在看 / 看过`；
- 页面末尾展示 4 份可复制工具的总览。

卡片操作文案：

- 未看：`开始学习`；
- 正在看：`继续学习`；
- 看过：`重新查看`。

### 2.2 章节详情

每章进入独立阅读视图，可复用现有 `detail.html?type=learn&id=...` 路由机制。详情页固定包含：

1. 返回 AI 新手入门；
2. 当前章节与 `01 / 06` 进度；
3. 概念主图；
4. 3–5 分钟核心内容；
5. 一个脱敏职场案例；
6. 一个 2–5 分钟互动练习；
7. 2–3 道“快速自测”或等价的互动反馈；
8. 一份可复制的本章模板；
9. `下一章` 与 `返回学习路径`。

不设置综合实战、结业考试、能力评分或证书。

## 3. 六章内容

### 3.1 认识 AI

目标：理解 AI、生成式 AI、大模型与 Agent 的关系，建立后续学习所需的最小概念框架。

核心内容：

- AI、生成式 AI、大模型、Agent 的包含与演进关系；
- 大模型根据前文预测下一个 Token；
- 预训练与每次对话的区别；
- 上下文是临时工作记忆，新对话不等于自动记住过去；
- Agent 是模型加目标拆解、工具调用和执行循环。

案例：为什么“我上次已经告诉过 AI”不代表新对话仍然知道。

互动：

- 点击观察候选 Token 的不同概率；
- 将四个概念放入正确关系；
- 复用现有大模型五步工作原理点击组件。

带走：AI 概念关系图与 8 个工作必懂词：Token、上下文、多模态、幻觉、RAG、Prompt、工作流、Agent。

可选背景：把现有 76 年时间线压缩成可折叠的 5 个关键节点，不作为必学内容。

### 3.2 看清边界

目标：知道 AI 擅长什么、不擅长什么，以及为什么流畅、自信的答案仍可能错误。

核心内容：

- 擅长：整理、改写、提取、归纳、初稿、发散和寻找模式；
- 需要人把关：事实确认、业务取舍、正式承诺和高代价判断；
- 幻觉来自“生成像答案的文本”，不是主动核实事实；
- 时效信息、内部信息和关键数据需要额外上下文或来源。

案例：AI 在汇报中生成了原始材料里不存在的精确增长数字。

互动“幻觉侦探”：点击回答中的句子，识别有依据、无来源和过度推断；结果使用“可以保留 / 需要核验 / 需要修改”，不做惩罚式红叉。

带走：AI 能力边界红黄绿清单。

### 3.3 学会分工

目标：判断一项工作应交给 AI、人机协作，还是必须由人负责。

核心内容：

- AI：格式化、整理、提取、初稿、方案发散；
- 人机协作：分析、汇报、决策准备、内容创作；
- 人负责：战略选择、优先级、对外口径、审批签字、利益协调；
- 判断维度：目标清晰度、可验证性、错误代价、业务语境与责任归属。

案例：月度汇报中的数据整理、异常分析、优先级判断和跨部门行动建议如何分工。

互动“任务分拣台”：把工作卡放入 AI、人机协作、人负责三栏；同时提供拖拽和点选两种方式。

带走：AI 任务分工五问。

### 3.4 把需求说清楚

目标：把提示词理解为工作 brief，而不是神奇口令。

核心内容：

- 四要素：目标、背景、任务、输出要求；
- 可选增强：好示例、不确定时的处理规则；
- 多轮协作：先结构、再补信息、再检查和修改；
- 第一版不好时给具体反馈，不必每次重新开始。

案例：把“帮我写一份工作汇报”逐步改成可执行的任务说明。

互动“Prompt 拼装器”：用户填写四个字段，页面实时组合完整 Prompt，可预览、修改、复制并与参考版本对照。

带走：四要素 Prompt 模板与常用反馈句式。

### 3.5 验证结果

目标：拿到 AI 回答后，能判断哪里可信、哪里需要核验。

核心内容：

- 区分事实、推论和观点；
- 核验五步：来源、原文、时间口径、推理关系、任务标准；
- 用准确、完整、相关、清晰、可追溯五项检查输出；
- “说得完整”与“有很多引用”都不能自动证明正确。

案例：AI 把“销量上升”直接解释为“营销活动有效”，但材料未排除其他因素。

互动：逐句标记事实、推论、观点；将回答与原文证据连接；比较两个版本的可用程度。

带走：AI 结果核验五步卡。

### 3.6 从对话走向工作流

目标：理解如何把一次成功对话沉淀为可以重复使用的方法。

核心内容：

- 一次对话：临时问题；
- Prompt 模板：同类任务重复使用；
- 工作流：固定输入、步骤、检查点和输出；
- Agent：在明确边界内围绕目标调用工具并循环执行；
- 沉淀五步：拆任务、定义输入输出、明确分工、设置检查点、保存模板。

案例：把每月重复的汇报任务从一次对话变成可复用流程。

互动：给工作步骤排序，指定 AI / 人 / 人机协作，并标出人工检查点。

带走：个人 AI 工作流画布。

## 4. 学习完成与返回机制

本期不做严格考试。章节完成采用轻量规则：

- 打开章节即记为“正在看”；
- 用户完成一次互动或查看练习解释后，可点击 `我看完了`；
- 点击后记为“看过”，无需达到分数线；
- 快速自测答错时只显示解释与“再想想”，仍可进入下一章；
- 用户可随时返回目录，不强迫完成本章。

完成后显示：

- `下一章`：主按钮；
- `返回学习路径`：次按钮；
- 最后一章只保留 `返回学习路径`。

返回目录后：

- 自动定位到刚才的章节卡；
- 卡片短暂高亮；
- 本次浏览状态继续显示；
- 浏览器原生返回键仍有效。

## 5. 无账号进度策略

学习进度只作为本次浏览的导航提示，不是考核记录。

- 使用 `sessionStorage` 保存 `未看 / 正在看 / 看过`；
- 同一标签页内跳转、返回和刷新时保留；
- 关闭标签页后自动清空，下次访问重新开始；
- 不承诺跨浏览器、跨设备或跨标签同步；
- 存储不可用时，阅读、互动、返回和下一章仍可使用，只是不显示累计进度。

## 7. 配图与动画

### 7.1 配图

复用现有小A Hero 和 3 张学习插图，新增 4 张同风格插图：

- 看清边界：AI 给出自信答案，人用放大镜核验证据；

- 验证结果：原始材料、AI 回答和核验清单；
- 从对话到工作流：对话、模板、工作流、Agent 四阶段。

新增图片延续现有蓝白扁平插画：深海军蓝、亮蓝、白色、细线和大面积留白；不使用渐变，不嵌中文文字，不带水印。标签由 HTML 叠加，保证准确和响应式。

### 7.2 轻交互

每章一组轻交互：

1. 概念关系与 Token 预测；
2. 幻觉句子标记；
3. 任务分拣；
4. Prompt 拼装；
5. 事实、推论、观点与证据连接；
6. 工作流排序与人工检查点。

动画使用 HTML、CSS 和少量 JavaScript，不制作自动播放的长动画。移动端同时支持点选；启用 `prefers-reduced-motion` 时关闭位移动画，功能和反馈保持完整。

## 8. 视觉与阅读体验

- 继续使用蓝白、无渐变视觉；
- 每章只设置一张主图，避免图片挤占正文；
- 知识内容使用白底阅读区；
- 案例使用浅蓝描边卡；
- 互动使用独立练习区，并明确“试一试”而非“考试”；
- 每章结尾固定显示“这一章你带走什么”；
- 正文字号沿用当前已放大的阅读标准；
- 桌面端显示轻量章节导航，移动端使用返回按钮与 `03 / 06` 进度；
- 所有交互可键盘操作，反馈不只依赖颜色。

## 9. 验收标准

- 学习目录只展示 6 个章节及 4 份带走工具，不出现外部资源目录；
- 每章有主图、案例、小练习、快速自测或等价反馈和带走模板；
- 无独立“安全负责”章节，无综合实战、结业考试、评分与注册要求；
- 状态为 `未看 / 正在看 / 看过`，不出现“未通过”；
- 章节可随时返回目录，返回后定位原卡片；
- 本次浏览内进度可用，关闭标签后自然重置；存储异常时页面仍可学习；
- 现有指定图片与交互被复用，新增 4 张插图风格一致、无渐变、无文字、无水印；
- AI 公司、模型、课程、视频、博主与外部链接只在“AI 工具与资源”出现；
- 1440、820、560、390px 均无横向溢出，章节返回、下一章、互动与键盘访问正常。
