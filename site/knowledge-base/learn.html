    01 · CONCEPT 建立认知

    AI 是什么

    用最通俗的方式理解人工智能：它能做什么、不能做什么，和我们的日常工作有什么关系。

    人工智能（Artificial Intelligence，AI）：让机器完成「通常需要人类智能才能完成」的任务——理解语言、识别图像、推理决策、生成内容。它不是一项单一技术，而是一个不断演进的技术族群：从早期的规则系统，到机器学习，再到今天的深度学习和大模型。

    一句话理解今天的主流 AI：它不是「查数据库」，而是基于海量数据学到的统计规律，对「下一个最合适的词 / 像素 / 动作」做预测。预测足够好，看起来就像「智能」。

    三个经常被混用的层次
    NARROW AI弱人工智能

    只擅长特定任务的 AI：下棋、翻译、推荐、画图。我们今天用到的所有 AI 都属于这一类，包括 ChatGPT 和大模型——强大但没有自我意识。

    AGI强人工智能

    假想中能像人一样跨领域学习、推理、解决任意问题的通用智能。目前仍是研究与争论的目标，定义和实现时间分歧很大。

    ASI超级智能

    假想中全面超越人类智能的形态，属于哲学与前瞻讨论范畴，也是 AI 安全与治理研究关注的长期议题。

    四个词，层层嵌套

    AI、机器学习、深度学习、大模型常被混用，其实是层层包含的关系，从外到内：

    人工智能 AI1956 年提出 · 让机器完成智能任务的总称
    机器学习 ML不写死规则，让机器从数据中自己学规律
    深度学习 DL用多层神经网络学习，2012 年起爆发
    大模型 / 生成式 AITransformer + 海量数据 · ChatGPT 以来的主流范式
    三要素：数据、算力、算法
    燃料数据

    互联网文本、图片、视频、代码是训练大模型的原料，规模与质量直接决定能力上限。

    引擎算力

    训练一次前沿大模型需数千张 GPU/加速卡连续工作数周，这也是英伟达成为 AI 核心供应商的原因。

    配方算法

    Transformer 架构 + 预训练 + 对齐微调是当前「标准配方」，算法创新（MoE、推理链）持续降本增效。

    大语言模型怎么工作：点一点，五步看懂
    收集语料

    用互联网上万亿级别的文字、代码、书籍作为学习材料。

    AI 像一个记忆力超强、但偶尔说梦话的天才实习生——好用，但不能完全信。 这就是「幻觉」（Hallucination）：模型的本质是概率预测而不是检索事实，重要信息一定要让它给出来源、或人工复核。
    AI 能帮你做 vs 暂时做不好
    放心交给 AI起草邮件 / 周报 / 文案；翻译与润色；整理会议纪要；把长文总结成要点；写初版代码与公式；头脑风暴与列提纲；解释陌生概念。
    仍需人来把关替你做最终决策；给出法律 / 财务 / 医疗的确定结论；保证 100% 准确的事实与数据；代替你对外的正式承诺；处理涉密的敏感信息（请走「小A」）。

    03 · PROMPT 核心技能

    Prompt / 提示词基础

    同一个 AI，有人觉得惊艳、有人觉得鸡肋，差别大多在「怎么提需求」。

    同样一个 AI，有人用得惊艳、有人觉得鸡肋，差距往往就在「怎么提需求」。提示词（Prompt）不是玄学，而是一套「把话说清楚」的结构化方法：把角色、任务、背景、格式讲明白，AI 的产出质量会明显提升。

    下面这套方法，可以直接套用到你真实的工作里。

    好提示词的四要素
    R · ROLE角色

    让 AI 扮演谁，如「你是一位资深电商文案」。

    T · TASK任务

    具体要做什么，如「写 3 条朋友圈推广文案」。

    C · CONTEXT背景

    必要的上下文：产品信息、目标人群、语气要求。

    F · FORMAT格式

    输出长什么样：表格 / 列表 / 字数限制 / 语言。

    直接可抄的模板

    把【】替换成你的内容即可，右上角按钮一键复制：

    你是一位【角色，如：资深零售行业培训讲师】。 背景：【事情的来龙去脉 / 素材，可粘贴原文】。 任务：请帮我【具体动作，如：把以上内容整理成 5 点培训要点】。 要求：【格式与限制，如：每点不超过 30 字，语气正式，输出为编号列表】。
    三个常见误区：换种写法，效果翻倍
    误区一 · 只说半句话「帮我写个邮件」——AI 只能瞎猜你的意图。
    更好写法「帮我写一封给供应商的交期确认邮件，语气礼貌但立场坚定，200 字以内」。
    误区二 · 一次想要全部把复杂任务一口气丢给 AI，输出往往又长又散。
    更好写法拆成多轮对话：先要框架、再逐段扩写、最后润色定稿。
    误区三 · 不给反馈第一版不满意就放弃，或重新开一轮对话从头再来。
    更好写法直接说「更口语化一点」「缩短一半」，AI 会立刻按反馈调整。

    练习入口：打开公司内部的「小A」，用上面的模板改造一个你本周真实的工作任务——练一遍，胜过读十篇教程。

    06 · GLOSSARY 随查随用

    AI 高频术语速查

    12 个高频术语：是什么、为什么重要、一句话记住。支持搜索过滤，点击条目展开。

    基础概念 先看这 6 个
    Token · 词元TOKEN
    是什么大模型不是「看字」，而是「看数字」。把一句话切成若干 token，每个 token 映射到一个数字再喂给模型。中文一般 1 个字 = 1~2 个 token，英文 1 个单词 ≈ 1 个 token。
    为什么重要① 决定一次能喂多少字（上下文窗口按 token 算）；② 决定 API 计费；③ 模型处理长文本的「内存压力」也按 token 衡量。
    例子句子「AI 改变工作方式」≈ 8 个 token；一段 3000 字的报告 ≈ 4500 token。
    Transformer · 注意力架构TRANSFORMER
    是什么谷歌 2017 年论文《Attention Is All You Need》提出的架构，核心是「自注意力机制」——模型读一句话时，每个字都能同时关注其他所有字，因此擅长理解长距离语义关系。
    为什么重要之前的 RNN/LSTM 必须逐字顺序读，速度慢、记不住长文；Transformer 可并行训练、能处理长文本，从此打开大模型时代。GPT、Claude、Gemini、Qwen、DeepSeek 全基于它。
    一句话今天所有主流大模型，本质都是「Transformer 家族的孩子」。
    预训练 · PretrainingPRETRAINING
    是什么第一阶段训练：把互联网上的书、新闻、代码、维基百科等数千亿 token 喂给模型，让它学会「下一个字该是什么」。这一阶段学到的是通用语言能力和基础知识。
    为什么重要训练一次的成本可达数百万到数千万美元，主要花在 GPU 算力上，所以大厂都是「一次预训练、多次微调」。
    一句话预训练是「读万卷书」，给模型打底。
    微调 · SFTFINE-TUNING
    是什么第二阶段训练：用人工写好的「问题-好答案」成对数据继续训练，让模型从「会接龙」变成「会按指令干活」。客服、法律咨询等场景都靠 SFT 调出「专业话术」。
    为什么重要相比预训练，SFT 需要的样本量小得多（几千到几万条），但能让模型行为更专业、更可控。
    一句话预训练是「读万卷书」，SFT 是「拜师学艺」。
    上下文窗口 · Context WindowCONTEXT
    是什么单次对话里模型能读多少字（输入 + 输出），单位是 token。早期 GPT-3 只有 4K token（约 2~3 页 A4）；如今旗舰模型已支持 100 万 token 级别（一整本小说）。
    为什么重要窗口越长，能喂的参考材料越多：长合同、长代码库、长会议记录都能一次性丢进去。它是和「智能水平」并列的核心指标。
    一句话窗口决定一次能「记住」多少。
    幻觉 · HallucinationHALLUCINATION
    是什么大模型的本质是「预测最可能的下一个词」，不是「查数据库」。当训练数据不足、问题模糊或被诱导时，它会一本正经地编造数据、引文、人名。
    为什么重要应对方法：① 重要事实人工复核；② 让模型给出来源/链接；③ 用联网搜索模式；④ 用 RAG 给模型喂真实文档。
    一句话AI 像一个记忆力强但偶尔说梦话的天才实习生——好用，但不能完全信。
    进阶概念 想深入再看这 6 个
    RLHF · 人类反馈强化学习RLHF
    是什么SFT 之后再做一轮「评分训练」：让人类对模型多个回答排序，模型就学会「什么是更好的回答」。
    为什么重要显著降低胡说八道、减少有害输出、提升指令遵循度。今天主流大模型几乎都用 RLHF（或它的变体 DPO、RLAIF）。
    一句话用人类偏好给模型「对齐价值观」。
    MoE · 混合专家MOE
    是什么Mixture of Experts。一个 MoE 模型内部有几十个「专家子模型」，每次只激活其中 2~4 个来处理当前输入。
    为什么重要总参数可能几千亿，但每次推理只调用一小部分，速度快、成本低。DeepSeek、Mixtral、Qwen 的旗舰模型都用了 MoE。
    一句话模型拆成多个专家，按需激活。
    多模态 · MultimodalMULTIMODAL
    是什么单模态 = 只能处理文字；多模态 = 文字、图片、音频、视频都能看懂 / 生成。GPT-4o、Claude、Gemini 的旗舰版本都是原生多模态模型。
    为什么重要拍照提问、识图翻译、视频生成、语音对话……这些玩法背后都是多模态能力。
    一句话让 AI 不止会读字，还会看图听声。
    推理模型 · Reasoning ModelREASONING
    是什么代表：GPT o 系列、DeepSeek-R1、Claude 的深度思考模式。它们在给出最终答案前会「自言自语」式拆解问题、写草稿、验算。
    为什么重要数学、代码调试、逻辑分析、多步推演——推理模型明显更强；代价是更慢、更贵。日常聊天、翻译、写作，普通模型就够了。
    一句话会「先想后答」的慢思考模型。
    Agent · 智能体AGENT
    是什么普通 AI = 你问它答；Agent = 你给它一个目标，它自己拆步骤、调工具（搜索、代码、文件、浏览器），遇到问题自己修，最终把活干完。
    为什么重要2025–2026 年 AI 竞争的主战场：从「会聊天」到「会干活」，办公自动化、代码开发、数据分析都在被 Agent 重构。
    一句话如果说 ChatGPT 是「会聊天的 AI」，Agent 就是「会干活的 AI 员工」。
    开源模型 · Open-Weight ModelOPEN-WEIGHT
    是什么权重公开、可私有化部署的模型。代表：Meta Llama、阿里 Qwen、DeepSeek、Mistral、智谱 GLM。
    为什么重要① 数据不出公司（合规）；② 可在自有服务器上跑；③ 可深度微调适配业务。代价是需要懂部署、有 GPU 资源；中小公司往往直接调用云 API 更划算。
    一句话开源 = 把模型「搬进自己家」的选项。
    没有匹配的术语，换个关键词试试。

    08 · HARD PARTS 难点与测验

    难点与常见误区

    新手最容易踩的 5 个坑，看懂它们能少走很多弯路；下方 8 题小测验即时检验你是否真的掌握。

    误区 1 · 幻觉AI 会一本正经地编

    大模型本质是「预测下一个词」，不是查数据库。重要数据、人名、引文务必让它给出来源，或人工复核。

    误区 2 · 提示词太短“帮我写个东西”说不清

    没写清角色、背景、任务、格式，AI 只能瞎猜。套用四要素模板，质量立刻不一样。

    误区 3 · 模型乱选复杂活交给普通模型

    推理、计算、长文档用推理模型（DeepSeek-R1、GPT o 系列）；公司数据一律走「小A」，合规又读得到内部资料。

    误区 4 · 一次喂太多长任务一口气丢过去

    输出又长又散。拆成多轮：先要框架、再逐段扩写、最后润色，效果更可控。

    误区 5 · 过度依赖AI 给的都当真

    AI 是「天才实习生」，不是权威。关键决策、对外口径、数据结论，一定保留人工判断。

    心态迭代比一次做对重要

    第一版不满意，直接说“更口语 / 缩短一半”，AI 会立刻改。多轮对话远胜重开新窗口。
